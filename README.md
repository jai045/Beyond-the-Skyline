# Data5ive – Housing Market Forecasting & Data Analytics

A data analytics and machine learning project focused on processing housing market data, exploring market trends, and developing forecasting capabilities using Python.

Developed as a collaborative university project at the **University of Illinois Chicago (UIC)** during Fall 2025.

---

## Project Overview

Data5ive is a collaborative data analytics project designed to explore housing market trends through data collection, processing, and analysis.

The project incorporates external data sources and structured data processing workflows to transform raw housing information into datasets suitable for analytical exploration and forecasting.

The application processes **15,000+ records** and incorporates data validation and ETL workflows to support data quality and consistency.

## Key Features

- **Data Collection:** Retrieves housing market information from external APIs.
- **Data Processing:** Processes and transforms datasets using Python and pandas.
- **ETL Pipeline:** Implements data extraction, transformation, and loading workflows.
- **Data Validation:** Applies data-integrity checks to improve dataset consistency.
- **Data Analytics:** Explores housing market information to identify patterns and trends.
- **Forecasting:** Applies machine learning techniques to housing market analysis.
